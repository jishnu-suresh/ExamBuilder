The save light

Your exam is safe once it is in a project file (.exam.json). The light next to the BEE name, at the top left, tells you where your work is.

LightWhat it meansWhat to do
🟢 GreenSaved in your project fileNothing
🟠 Orange: "Only in this browser"Not in a file yetClick it, or 📁 File → 💾 Save as…
🔴 Red, with a red barNot savedClick 💾 Save to a file in the bar

Click the orange light, type a name and click Choose folder & save. From then on BEE saves to that file by itself, every minute.

In Safari and Firefox, the file goes to your Downloads folder: save again with 📁 File → 💾 Save as… when you have finished.

Open, save as, new

📁 File has New, Open and Save as. To open an exam, choose its .exam.json file; if BEE is installed as an app, double-click the file.

Save as… makes a copy under a new name: handy for next year's version.

Undo

Deleted a question by mistake? Click ↩️. ↪️ redoes. Ctrl/⌘+Z works too.

Earlier versions

While you work, BEE keeps earlier versions of your exam in this browser. Click 🕰️ History to see them, and Restore to bring one back. Your current work is kept as a version first.

On a shared or classroom computer

When you finish, click 🧹 Remove my exams from this browser. It is on the start screen and in the 🕰️ window. Otherwise the next person to open BEE on that computer can see your exam and its answer key. Your saved files are not touched.
A yellow bar saying BEE is open in another tab or window too? Two open copies can overwrite each other: save in one, then close the other.
