🚀Getting started

Open BEE, start an exam, take the tour

Open BEE

Open jishnu-suresh.github.io/ExamBuilder in Chrome or Edge. They work best, because BEE can keep saving to your exam file in these browsers. Safari and Firefox work too, but you save by hand there.

  • Install it as an app (recommended): in Chrome or Edge, click ⤓ Install app in the top bar. BEE then gets its own icon and window, and works without internet.
  • On a Mac with Safari: File → Add to Dock gives you an icon too.
  • Updates arrive by themselves. When a new version is ready, a bar says Fresh honey in the hive! Click 🐝 Update now. Your work stays safe.

Start a new exam

1

Name it and choose a folder

Click ＋ New exam and type a name, for example Grade 7 Maths - Unit 4 test. The small buttons add the date, a version number or "copy".

Click Choose folder & save and pick a folder, such as Documents. This file, ending in .exam.json, is your exam: BEE saves to it by itself every minute.

The light at the top turns 🟢 green.

The 1-minute tour

2

Four stops

On the start screen, click New here? Take the 1-minute tour →. A ring moves round the screen: exam details, questions, preview, download. Press Next →, or Skip tour at any time.

Basic mode: fewer buttons

3

Switch with 🍯🐝

Too many buttons? Click 🍯🐝 at the top to switch to 🌱 Basic mode. It shows only the everyday buttons: the Download menu, for example, keeps the paper, large print, dyslexia-friendly and the key.

Click 🌱 Basic again to see every option. BEE remembers your choice on this computer.

In this guide, features marked all options are hidden in Basic mode.
